# Taller ficticio: asistentes de soporte

El equipo de ejemplo prepara una demostracion interna para el 18 de diciembre.
La audiencia son desarrolladores .NET. El objetivo es resumir una solicitud
sintetica y proponer una siguiente accion sin modificar sistemas.

El taller reserva 20 minutos para explicar cliente y sesion, 15 minutos para
una consulta local de solo lectura y 10 minutos para revisar limites y preguntas.
El resto del tiempo se usa para introduccion y cierre.

La persona facilitadora debe confirmar el modelo disponible y ensayar el flujo
antes de la sesion. No se define quien aprobara el modelo ni se promete una
integracion con sistemas de soporte reales.
